# 💘 카톡 관계 분석기 (썸 · 친구 · 팀플)

카카오톡 대화 내보내기 파일을 올리면 선톡, 답장 속도, ㅋㅋ 지수 등을 분석해서 썸 판정을 내려주는 Streamlit 앱입니다.

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 파일 구성
| 파일 | 역할 |
|---|---|
| `app.py` | Streamlit 화면 (썸 모드 + 모드 전환) |
| `ui_modes.py` | 친구 모드 · 팀플 모드 화면 |
| `analyzer.py` | 파싱(PC·안드로이드·iOS·CSV, 한/영) + 분석 로직 + 샘플 대화 |
| `share_card.py` | 인스타 스토리용 결과 카드 PNG 생성 |
| `packages.txt` | Streamlit Cloud 배포 시 한글 폰트(나눔고딕) 설치 |
| `fonts/` | 결과 카드용 한글 폰트를 직접 넣고 싶을 때 (.ttf/.otf) |

## 기능
### 👯 친구 모드
- 우정 판정(평생 베프 · 놀 때 부르는 친구 · 연락 끊기기 직전…), 우정 온도, 꾸준함, 누가 더 챙길까
- 우정 유형(드립 장인, 고민 상담소장, 약속 총무…), 우정 위기 감지, 단톡 생존율, 베프 짝꿍, 단톡방 역할

### 🛠️ 팀플 모드
- 기여도 랭킹(항목별 근거), 무임승차 탐지기, 팀원 역할(팀장 · 자료 담당 · 넵 봇…), 팀 유형, 마감 텐션 그래프

### 💘 썸 모드
- 💞 썸 판정, 🌡️ 썸 온도, ⚖️ 마음의 지분(항목별 근거)
- 🏅 칭호 뱃지, 📆 주차별 썸 타임라인, 🎬 명장면(역대급 수다, 최장 읽씹, 첫 고백성 멘트…)
- 👥 단톡방 모드: 어워즈, 썸 의심 커플 TOP 3, 답장 관계도 히트맵
- 📸 1080×1920 결과 카드 다운로드
- 🛡️ 가명 처리, 전화번호·이메일·링크·계좌번호 자동 마스킹, 분석 기간 필터
- ℹ️ 분석 방법·한계 설명 탭

※ 재미용 지표이며 실제 연애 결과로 검증된 모델이 아닙니다.
